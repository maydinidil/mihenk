# 0001: Name and repository

Date: 2026-10-09. Status: decided.

## The name

The project is called **mihenk**, chosen on 2026-10-09. It is Turkish for touchstone (*mihenk
taşı*), the stone used to test gold, and it is also a Turkish word for a benchmark. That fits the
app: it tests every price against its source.

## Why the first choice was dropped

The first choice was **karat25**. It was dropped after an EU trademark register search found the
word mark KARAT registered for software, in classes 9 and 42. Using a name that close in the same
field risks a conflict, so Aydin chose another name.

## What was and was not checked

| Check | Result |
|---|---|
| EU register search for karat25 | Done. KARAT is registered for software (classes 9 and 42) |
| Register search for mihenk | Not run. This was Aydin's decision |
| GitHub name check for `maydinidil/mihenk` | Free on 2026-10-09 |

## The repository

The planned address is `https://github.com/maydinidil/mihenk`.
